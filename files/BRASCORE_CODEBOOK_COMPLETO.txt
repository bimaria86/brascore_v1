NOTAS IMPORTANTES
=================

1. VALIDAÇÕES CONDICIONAL
   - Muitos campos são "condicional": aparecem apenas se um campo anterior atende certas condições
   - Exemplo: Se diabetes=Não, o campo "diabetes_control" não é requerido

2. ENCRIPTAÇÃO LGPD
   - Dados sensíveis (nome, CPF, telefone) DEVEM ser encriptados em repouso
   - Use AES-256 com chaves em variáveis de ambiente

3. FÓRMULAS CALCULADAS
   - IMC = weight_kg / (height_cm/100)²
   - Estes campos não precisam ser preenchidos; são calculados automaticamente

4. CAMPOS ÚNICOS
   - patient_id: Único globalmente (UUID)
   - med_record + hospital_id: Único por hospital (chave composta)

5. ÍNDICES RECOMENDADOS
   - patient_id, hospital_id, admission_date, surgery_date
   - Para performance em queries de filtro

6. AUDITORIA
   - TODAS as mudanças são registradas em audit_logs
   - Nunca usar DELETE direto; usar soft delete (flag)

7. VARIÁVEIS "SOLTAS" A REMOVER
   - ~80 campos não estão neste codebook
   - Estes devem ser removidos após auditoria
   - Consultar com Comitê BraSCORE antes de deletar
